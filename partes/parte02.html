Parte 02: Navegador de Internet

Comunicación, Búsqueda y Gestión Web

1. Conceptos básicos de Internet

Internet es una red global de computadoras interconectadas que comparten información. Para acceder a las páginas (World Wide Web) usamos "Navegadores" (como Chrome o Firefox). Cada página web tiene una dirección única conocida como URL (por ejemplo: www.uncp.edu.pe), la cual escribimos en la barra de direcciones.

2. Navegación web segura y eficiente

Para navegar con seguridad, siempre verifica que la página tenga un candado al lado de la URL (protocolo HTTPS), lo que significa que la conexión es privada. Evita hacer clic en anuncios engañosos o descargar programas de sitios no oficiales para prevenir el robo de información (Phishing) o virus.

Práctica: Revisa el remitente real de los correos y nunca ingreses contraseñas en enlaces sospechosos.
3. Uso de motores de búsqueda

Un motor de búsqueda (como Google) es una herramienta que busca información en toda la red según las palabras clave que ingreses. Para búsquedas académicas o avanzadas, es muy útil utilizar operadores de búsqueda especiales que filtran los resultados con precisión.

Trucos de búsqueda (Google):
"texto exacto" Busca la frase tal cual.
site:edu.pe Busca solo en páginas de universidades peruanas.
filetype:pdf Encuentra únicamente documentos PDF.
4. Manejo de Google Chrome y Mozilla Firefox

Los navegadores modernos usan un sistema de "Pestañas" que permite tener muchas páginas abiertas en una sola ventana. Además, puedes guardar tus páginas frecuentes en los "Marcadores" o "Favoritos", y consultar páginas que visitaste anteriormente en el "Historial".

Atajos:
Ctrl + T Nueva pestaña. Ctrl + W Cerrar pestaña.
Ctrl + Shift + T Recuperar la última pestaña cerrada (¡Muy útil!).
Ctrl + D Guardar página en Favoritos.
5. Descarga y gestión de archivos

Todo archivo que bajes de Internet se guardará por defecto en la carpeta "Descargas" de Windows. Para mantener el orden, es recomendable mover inmediatamente los documentos importantes a sus carpetas correspondientes (por ejemplo, "Trabajos de Agronomía") y eliminar los instaladores que ya no necesites.

Atajo (Navegador): Ctrl + J Abre el historial de Descargas del navegador.
6. Envío y recepción de archivos por correo electrónico

Plataformas como Gmail u Outlook permiten adjuntar archivos (botón con forma de clip) a los mensajes. Existe un límite de tamaño (generalmente 25 MB). Si el archivo es muy pesado, debes subirlo a la nube (como Google Drive o OneDrive) y enviar solo el enlace generado.

Práctica: Si envías varios documentos juntos, primero compáctalos en un archivo .zip para facilitar la descarga al destinatario.
7. Compartir archivos y contenidos en redes sociales

Aplicaciones como WhatsApp Web, Telegram o Microsoft Teams (muy usado en la UNCP) permiten transferir archivos de forma instantánea. WhatsApp tiene límites en el tamaño de videos, mientras que Telegram y Teams permiten el envío de archivos mucho más pesados sin perder tanta calidad.

Práctica: En WhatsApp Web, puedes simplemente arrastrar un documento desde el Explorador de Windows directamente a la conversación para enviarlo rápido.
