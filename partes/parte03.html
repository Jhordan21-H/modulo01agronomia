Parte 03: Microsoft Word 2024

Procesamiento Profesional de Textos

1. Introducción a Microsoft Word

Microsoft Word 2024 es el procesador de textos estándar de la industria, diseñado para crear desde notas sencillas hasta tesis universitarias completas, con herramientas integradas de revisión y diseño.

Inicio y cierre de la aplicación

Para abrir Word, búscalo en el menú Inicio o presiona Win y escribe "Word". Para cerrarlo, puedes usar el botón X en la esquina superior derecha, ir a Archivo > Cerrar, o utilizar atajos de teclado.

Creación y manipulación de documentos

Al abrir, se muestra la "Pantalla de inicio", donde puedes elegir un "Documento en blanco" o una de las plantillas predefinidas (currículums, informes, etc.). Manipular un documento implica guardarlo correctamente desde el inicio para evitar pérdida de datos.

Atajos Fundamentales:
Ctrl + U Crear un nuevo documento en blanco.
Ctrl + A Abrir un documento existente.
Ctrl + G Guardar los cambios (Guardar).
F12 Guardar como (ideal para cambiar el nombre o formato a PDF).
Alt + F4 Cerrar Word.
2. Edición de Texto

Seleccionar, copiar, mover y eliminar texto

La selección eficiente es clave: doble clic selecciona una palabra, triple clic selecciona el párrafo entero. Para mover texto, debes cortarlo y luego pegarlo. Para duplicarlo, cópialo y pégalo. Elimina con Supr (borra hacia adelante) o Retroceso (borra hacia atrás).

Deshacer y rehacer acciones

Word tiene memoria de las acciones que realizas. Si borraste algo por error o aplicaste un formato que no te gustó, no necesitas borrarlo manualmente, simplemente deshaz la acción. Si deshaces demasiado, puedes rehacerlo.

Atajos de Edición (Versión Español):
Ctrl + C Copiar | Ctrl + X Cortar | Ctrl + V Pegar.
Ctrl + Z Deshacer la última acción.
Ctrl + Y Rehacer la última acción deshecha.
Ctrl + E Seleccionar TODO el texto del documento.
3. Formato de Texto

El formato de texto cambia la apariencia de los caracteres (letras) sin alterar la estructura del párrafo. Se encuentra en la pestaña Inicio, en el grupo Fuente.

Tipo, tamaño, estilos y color de fuente

Las fuentes (tipografías) más usadas en la academia son Arial o Times New Roman tamaño 11 o 12. Los estilos principales son Negrita (para resaltar), Cursiva (para extranjerismos o énfasis) y Subrayado. Puedes cambiar el color del texto y aplicar resaltado.

Letra capital

Es una letra de gran tamaño al principio de un párrafo, usada a menudo en artículos y libros. Se inserta desde la pestaña Insertar > Letra capital, eligiendo si va "En texto" o "En margen".

Atajos de Formato (Versión Español):
Ctrl + N Aplicar Negrita.
Ctrl + K Aplicar Cursiva.
Ctrl + S Aplicar Subrayado.
Ctrl + Shift + > / < Aumentar / Disminuir tamaño de fuente.
4. Formato de Párrafos

El formato de párrafo afecta a todo el bloque de texto hasta el punto y aparte (Enter). Se gestiona desde la pestaña Inicio, grupo Párrafo.

Alineación

Define cómo se alinea el texto respecto a los márgenes: Izquierda (por defecto), Centrada (para títulos), Derecha (para fechas/firmas), o Justificada (alineada a ambos lados, ideal para documentos formales de la universidad).

Sangrías y Espaciado

Sangría: Es el espacio desde el margen hasta donde empieza el texto. La más común en normas APA es la "Sangría de primera línea".
Espaciado: El "Interlineado" es el espacio vertical entre líneas (ej. 1.5, doble). El "Espaciado de párrafo" es el espacio antes y después de cada bloque de texto.

Atajos de Alineación e Interlineado:
Ctrl + Q Alinear a la Izquierda | Ctrl + T Centrar.
Ctrl + D Alinear a la Derecha | Ctrl + J Justificar.
Ctrl + 1 Interlineado sencillo (1.0).
Ctrl + 5 Interlineado de 1.5 líneas.
Ctrl + 2 Interlineado doble (2.0).
5. Diseño de Página

Antes de redactar documentos oficiales, se debe configurar el lienzo de trabajo desde la pestaña Disposición (o Diseño de página).

Márgenes, Tamaño y Orientación

Márgenes: Es el espacio en blanco alrededor de la hoja. Para normas APA se usa 2.54 cm en todos los lados.
Tamaño del papel: Por defecto suele estar en formato A4 (el estándar en Perú) o Carta (Letter).
Orientación: Puede ser Vertical (Portrait) o Horizontal (Landscape). Idealmente, se puede usar "Saltos de sección" para tener hojas verticales y horizontales en el mismo documento.

6. Herramientas Avanzadas

Numeración, viñetas y tabulaciones

Las viñetas (puntos) y la numeración (1, 2, 3) organizan listas. Las tabulaciones permiten alinear datos en posiciones específicas usando la regla superior (muy útil para índices manuales o firmas múltiples).

Encabezados, pies de página y numeración

Accedes a ellos haciendo doble clic en el margen superior o inferior. El texto colocado aquí se repetirá en todas las hojas. Desde la pestaña Insertar, puedes agregar el número de página automáticamente.

Notas al pie y Columnas

Notas al pie: (Pestaña Referencias) Añaden una aclaración al final de la página (ej. definición de una palabra técnica).
Columnas: (Pestaña Disposición) Divide el texto en 2 o más columnas periodísticas, útil para artículos de investigación tipo paper.

Atajos Rápidos:
Alt + Ctrl + O Inserta una nota al pie de página automáticamente.
Tab Aumentar nivel de lista/sangría | Shift + Tab Reducir.
7. Objetos y Elementos

La pestaña Insertar es la clave para enriquecer el documento visualmente y añadir funcionalidad.

Tablas y Gráficos

Las Tablas organizan información en filas y columnas. Al insertar una tabla, se activan pestañas emergentes para su diseño. Los Gráficos integran un pequeño panel de Excel para tabular datos estadísticos.

Hipervínculos

Permiten que un texto sea "cliqueable" y te lleve a una página web externa, a otra parte del mismo documento, o a un correo electrónico.

Bases de datos simples (Correspondencia)

La pestaña Correspondencia permite enlazar Word con una base de datos de Excel. Útil para crear 100 diplomas o cartas personalizadas automáticamente a partir de un solo documento maestro. Se le conoce como "Combinar Correspondencia".

Atajos Rápidos:
Ctrl + Alt + K (o Ctrl + K dependiendo del idioma) Inserta un hipervínculo en el texto seleccionado.
8. Impresión de Documentos

El paso final antes de entregar físicamente el trabajo.

Configuración y Vista previa

Antes de imprimir, siempre revisa la vista preliminar para asegurar que ningún gráfico o tabla quede cortado. En la configuración puedes elegir qué impresora usar, imprimir a doble cara, e imprimir múltiples páginas en una sola hoja (útil para borradores y ahorrar papel).

Impresión final

Puedes elegir imprimir "Todo el documento", "Solo la página actual", o un rango personalizado (ej. páginas "1, 3, 5-10").

Atajo Principal:
Ctrl + P Abre instantáneamente la ventana de Impresión y Vista Preliminar.
